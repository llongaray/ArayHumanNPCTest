Aray Human NPC Test v0.1 - Project Zomboid Build 42.13.1

INSTALL
1. Close the game.
2. Extract ArayHumanNPCTest into C:\Users\<your user>\Zomboid\mods\
3. Enable "Aray Human NPC Test" in the Mods menu.
4. Disable NPC Helper Mod for this experiment.
5. Test only on a new disposable save.

This is an experimental Lua/Java class access test. IsoSurvivor may not be exposed to Lua, may fail to render, or may not update. No persistence or AI is implemented.

Check C:\Users\<your user>\Zomboid\console.txt for [ARAY].
